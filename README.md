# Glimpshot

A fast, good-looking screenshot tool for macOS, in the spirit of Lightshot.
Native for Apple Silicon. Everything stays on your Mac — no accounts, no uploads.

## Features

- Area capture with window snapping, a pixel loupe and a live size readout
- Annotations: pen, line, arrow, rectangle, ellipse, highlighter, text, pixelate, numbered steps
- Copy, save, save as, or pin the screenshot above all windows
- Corner preview you can drag into other apps, and a local history of saved shots
- 11 languages, custom accent color, configurable shortcuts

## Install

Download the DMG from [Releases](../../releases), open it and drag Glimpshot to Applications.
On first capture, allow Glimpshot in **System Settings → Privacy & Security → Screen & System Audio Recording**, then relaunch it.

## Shortcuts

| | |
|---|---|
| ⌘⇧2 | Capture area (click a window to select it) |
| ⌘⇧1 | Capture the screen under the cursor |
| ↩ / ⌘C | Copy and close |
| ⌘S / ⇧⌘S | Save / Save as |
| ⌘P | Pin on top |
| Esc | Cancel |

Tool keys and more are listed in Settings.
